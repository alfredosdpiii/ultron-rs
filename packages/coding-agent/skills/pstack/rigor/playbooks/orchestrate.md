### Orchestrate

**You own the program, never the code. Brief, drain completions, keep the frontier green, decide.** Use this for a queue of PRs that one agent cannot finish in its budget. One task driven to a checkable predicate is `playbooks/autonomous-run.md`. Work one agent can finish is not a program: do it directly.

The run is a `/goal` whose exit condition is written first: every unit merged (Full) or verified and handed off (Stack), with nothing delegated left.

1. **Gates first.** Items the operator names as theirs, and PRs outside the queue, stop at merge-ready. A request to state the plan is not a go. Write the plan and stop until the operator says go.
2. **Pick the shape and write it into the standing orders.**
   - **Full.** Independent PRs, landing authority granted. One owner per PR carries it from build to merge, and nothing merges without a clean verdict from a verifier that did not write the code.
   - **Stack.** The operator wants review before landing, or the work is coupled. Owners build and verify, stacking a PR only on a PR it builds on, and stop at verified. Nobody pushes after the handoff without the operator's go.
3. **Spawn one owner per PR, in parallel off trunk, never stacked** (Stack excepted). Each owner is a `rlm.spawn(brief, name=..., worktree=True, model=state["models"]["code"], timeout_ms=...)`. Set `timeout_ms` to at least the longest past run of that kind, so a stuck child ends and arrives as an event. The brief starts with `Read <absolute path of this skill>/worker.md before anything else.`, then the goal, the PR's scope, and `playbooks/opening-a-pr.md` and `playbooks/babysit.md`. An owner opens its PR per `playbooks/opening-a-pr.md`, proves the change on the real surface, and babysits to green. It rebases its own branch only, and publishes with `--force-with-lease` pinned to the SHA it last pushed. The root never writes code.
4. **Verify once.** A verifier runs at the code-ready head on `state["models"]["judgment"]`, a different family from the owner where the pool allows, and re-runs the gates and proves the load-bearing behavior on the real surface. A rebase, a conflict fix, or a minor fix gets one verifier at the new head. A wording-only change gets none. Block a PR only for a failing run at this head or a bug a user would hit, and report anything the base already has in one line.
5. **Merge only what was verified, on the trunk it lands on.** Green CI alone never authorizes a merge. Right before merging, fetch trunk and ask whether its changes can affect the patch. Rebase and wait for CI when the code that would land was never tested. When trunk changed a caller of the patch, run the patch's checks on the merge result and merge on a pass. Otherwise merge with `gh pr merge <pr> --squash`, then read the PR back.
6. **Run the root layer.** Anything that loosens a gate needs a verifier's proof and the root's countersign. Never bypass an approval the forge enforces. A disabled or soft-failed check comes back on, because it stops guarding every case.
7. **Audit on events, not timers.** Each child completion is a queue event; drain it, then continue. Check each agent through `rlm.progress()` when a completion arrives. A child that errors or goes quiet past its `timeout_ms` is replaced at once. Do not sleep, poll or loop over a child. A watch on an open PR is `schedule.watch_pr(...)` from `playbooks/babysit.md`.
8. **Stand down on the operator's stop.** A hold reaches every owner as a zero-writes order. Each reports where it stands and keeps its brief until the operator releases it.

**Reply:** catch the operator up per the **ketchup** skill: each PR's state and verdict, what merged, countersigns and why, open operator gates, parked follow-ups, and links to each PR.
