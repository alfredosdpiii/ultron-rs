# Settings, clean-up and updates

Read this when SKILL.md section 0 sends you here.

When the arguments for this call (the text after the skill block, see section 0 of SKILL.md) start with `config` (for
example `/skill:answer-me-with-html config open off`), this turn handles settings only and produces no page:

- `config`: run `am config` to show the current settings, then let the user choose. Ask in plain text, at most 4
  settings at a time, these first: `open`, `theme`, `mode`, `style`, with the current value marked.
- `config <key> <value>`: run `am config set <key> <value>`.
- `config reset [key]`: run `am config reset [key]`.

When the user asks in natural language ("stop opening the browser", "use the card theme by default"), also convert it to
`am config set`. Settings: `open` (auto-open the browser), `theme`, `mode`, `style`, `scale` (text size on the page;
diagrams and charts grow with it), `voice` (video narration), `close_after_reply` (close the page tab after the reply is
copied), `colophon` (the "Generated by" line above the title). Run `am config` to see all descriptions. `am` means the
command from SKILL.md section 2.

Leave `update_check` alone: Ultron runs the CLI with `AM_NO_UPDATE_CHECK=1`, so it never downloads its version files.

When the user asks for a ready-made theme ("use the comic theme", "install the manga theme"): run
`am theme add <name> --use`. Names come from the catalog at https://answer-me-with-html.com/themes/ (at the time of
writing: `comic`, `manga`, `pop`); if the name is not there, the command lists the available ones. It downloads, checks
and saves the theme and makes it the default, and it asks the user nothing else. If it stops because a file of that name
already exists, tell the user it may be their own theme and run it again with `--force` only if they agree.
`am theme list` shows the installed themes (`--remote` also shows the catalog), `am theme update` updates them, and
`am theme remove <name>` deletes one. The command prints only theme names and versions; it needs Answer me with HTML
0.5.3 or newer.

When the arguments start with `clean`, or the user asks to clean up pages / the cache: first run `am clean --dry-run`
and tell the user how many items and how much space will be deleted. Run `am clean` only after the user agrees (add
`--all` to delete all pages, videos and saved drafts, `--days N` to change how many days to keep).

When the arguments start with `update`, or the user asks to update this skill: this copy ships with Ultron and updates
with it. Tell the user to update Ultron (`npm install -g ultron-agent`); do not run `npx skills`, `claude plugin`,
`dsh plugin` or `git pull` for it.
